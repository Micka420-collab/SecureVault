About SecureVault

🔐

SecureVault Browser Extension

Version 1.0.0

SecureVault is a self-hosted password manager designed for maximum privacy. Your data is encrypted locally and stored on your own server.

Features

  • Zero-knowledge encryption
  • Tailscale network integration
  • Auto-fill login forms
  • Password generation
  • Secure sharing
  • Emergency access
